Purble Place reconstruction — web build

This page is the reconstruction's own viewer compiled to WebAssembly. It contains no game art, no sound and no Microsoft code: the game reads the resource files from an installation of Purble Place that you select. Nothing is uploaded; the files are read in the browser and written into the page's own memory.

1. Select the game files

Pick these files from a Purble Place installation (the three DLLs usually sit next to PurblePlace.exe, and the .mui is in its en-US folder):

FileRequiredFound
or drop the files (or the whole game folder) here

2. Sound (optional)

The shipped effects are WMA, which only Windows can decode, so the game is silent until it is given a sound pack: one WAV per sound, made once by the desktop build. 

pple-res audio-pack PurblePlace.dll PurblePlace2.dll CardGames.dll --out audio

No sound pack selected; the game will play silently.

Click the picture first if the keyboard does not answer. ESC leaves a game and quits from the menu.
